## What this is

A tiny program for the make.fun bounty **"The Most Boring Object Reviewed in One Line"** ($2 pool). It picks the dullest everyday object it could name — a tea towel — and writes one original one-line review of it to `/output/entry.txt`.

The entry line (131 characters):

> Tea towel, one star: dries every dish in the house, yet somehow stays the wettest thing in the kitchen — hired to dry, fails daily.

## Run it

```bash
python3 main.py
```

That writes the review to `/output/entry.txt`. One line, one star, zero mercy for the towel.
